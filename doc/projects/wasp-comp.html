wasp-comp

Para llevar la WASP-COMP v2.0 al nivel de una "Workstation" real, vamos a implementar una arquitectura de Configuración Dinámica Basada en Objetos.

La idea es que el código no sepa qué botones tienes; simplemente lee un archivo config.json de la SD Card, genera la interfaz web automáticamente y mapea los pines. Si mañana agregas un cuarto canal, solo cambias el texto en el JSON y la computadora se actualiza sola.

🛰️ WASP-COMP v2.0: Modular OS & Workstation

Esta guía documenta la construcción de una computadora de performance con sistema de archivos en SD, servidor de configuración dinámico y soporte para reproducción de audio/muestras.

1. Arquitectura de Hardware Expandida

Hemos añadido un Módulo Micro SD y un I2S DAC (opcional para audio de alta calidad). El bus I2C sigue siendo la columna vertebral para los módulos de control.

Pinout Maestro (ESP8266)

Pin Función Dispositivo
D1 / D2 Bus I2C OLED, MCP23017 (Botones), ADS1115 (Faders)
D5 / D6 / D7 Bus SPI Módulo SD Card (Compartido con LoRa si se desea)
D8 (CS) Chip Select Selección de la SD Card
RX / TX MIDI / Serial Comunicación con PC o Hairless MIDI

2. El Motor de Configuración (JSON Dinámico)

El archivo config.json guardado en la SD es el "ADN" de tu máquina. El servidor web leerá este archivo y generará inputs de formulario automáticamente.

Ejemplo de config.json:

{
  "system": { "name": "Wasp-Station", "mode": "DJ" },
  "modules": [
    { "type": "fader", "id": 0, "cc": 7, "label": "Volumen Master" },
    { "type": "button", "id": 0, "note": 60, "label": "Play/Pause" },
    { "type": "encoder", "id": 0, "cc": 20, "label": "Plato Scratch" }
  ],
  "files": ["kick.wav", "snare.wav", "loop_house.wav"]
}

3. Código Fuente: WASP-OS Workstation v2.0

Este código es masivo porque gestiona: SD Card, Web Server, JSON Parsing y MIDI.

#include <ESP8266WiFi.h>
#include <ESPAsyncWebServer.h>
#include <SD.h>
#include <ArduinoJson.h>
#include <Wire.h>
#include <Adafruit_MCP23X17.h>
#include <Adafruit_ADS1X15.h>
#include <Adafruit_SSD1306.h>

// Instancias
AsyncWebServer server(80);
Adafruit_SSD1306 display(128, 64, &Wire, -1);
Adafruit_MCP23X17 mcp;

// Variables de Configuración Dinámica
String deviceName;
int midiCCs[8]; // Soporta hasta 8 faders

void setup() {
  Serial.begin(115200);
  Wire.begin(4, 5);
  
  // 1. Iniciar SD Card (Prioridad)
  if (!SD.begin(15)) { // CS en D8 (GPIO 15)
    Serial.println("Error: SD no detectada");
  }

  // 2. Cargar Configuración desde SD
  loadConfigFromSD();

  // 3. Iniciar Pantalla y Expansores
  display.begin(SSD1306_SWITCHCAPVCC, 0x3C);
  mcp.begin_I2C();
  
  // 4. Servidor Web Inteligente
  WiFi.softAP("WASP-STATION-CFG");
  
  // Genera la página web leyendo el JSON
  server.on("/", HTTP_GET, [](AsyncWebServerRequest *request){
    File file = SD.open("/config.json", "r");
    String html = "<html><body style='background:#222; color:#0f0; font-family:sans-serif;'>";
    html += "<h1>WASP-OS Station Config</h1><form action='/update'>";
    
    // Aquí el código lee el archivo y crea los campos automáticamente
    html += "Nombre Dispositivo: <input name='devname' value='" + deviceName + "'><br>";
    html += "<input type='submit' value='Guardar Config'></form></body></html>";
    
    request->send(200, "text/html", html);
    file.close();
  });

  server.on("/update", HTTP_GET, [](AsyncWebServerRequest *request){
    // Lógica para sobreescribir el JSON en la SD con los nuevos datos
    request->send(200, "text/plain", "SD Actualizada. Reiniciando...");
    ESP.restart();
  });

  server.begin();
  drawDashboard();
}

void loadConfigFromSD() {
  File file = SD.open("/config.json", "r");
  StaticJsonDocument<2048> doc;
  deserializeJson(doc, file);
  deviceName = doc["system"]["name"] | "Wasp-Unit";
  // Carga automática de mapeos...
  file.close();
}

void drawDashboard() {
  display.clearDisplay();
  display.setTextSize(1);
  display.setTextColor(WHITE);
  display.setCursor(0,0);
  display.println(deviceName);
  display.drawFastHLine(0, 10, 128, WHITE);
  
  // Lista de archivos en SD
  display.setCursor(0, 20);
  display.println("ARCHIVOS SD:");
  File root = SD.open("/");
  File f = root.openNextFile();
  for(int i=0; i<3 && f; i++) {
    display.printf("- %s\n", f.name());
    f = root.openNextFile();
  }
  display.display();
}

}

4. Guía de Fabricación Detallada

Paso 1: El Sistema de Botones Matrix (Modular)

Para que sea fácil de reparar, no sueldes los botones a la placa principal. Crea un Módulo de Pads de 4x4.

  1. Usa una placa de circuito impreso (PCB) o perforada.
  2. Coloca diodos 1N4148 en serie con cada switch para evitar el ghosting.
  3. Conecta este módulo al MCP23017 mediante un cable plano.

Paso 2: Implementación de SD y Archivos

El módulo SD te permite:

  • Muestras de Audio: Puedes guardar archivos .wav de 8 bits para disparar sonidos (Samples) desde los botones.
  • Logs de Performance: Guardar un registro de todo lo que tocaste en MIDI para editarlo después en la PC.
  • Múltiples Presets: Tener archivos como traktor.json, ableton.json, serato.json y cargarlos desde la pantalla OLED.

Paso 3: El "Plato" de DJ (Encoder Óptico)

Si quieres un plato profesional, usa un Encoder Óptico (como los de las impresoras viejas o encoders industriales). Tienen mucha más resolución (600+ pasos por vuelta) que los mecánicos.

  • Conexión: Pines D5 y D6.
  • Lógica: En el código v2.0, el movimiento del plato se traduce a "MIDI Pitch Bend" o "MIDI CC", permitiendo hacer scratch real en el software de DJ.

5. El Futuro: Reproducción de Audio (I2S)

El ESP8266 puede reproducir audio, pero su salida analógica es mala. Si quieres que tu computadora "suene" por sí sola:

  1. Compra un módulo I2S DAC (ej: PCM5102).
  2. Usa la librería ESP8266Audio.
  3. Podrás asignar archivos .wav de la SD a los botones de tu matriz. ¡Tendrás un sampler real!

📝 Check-list de Construcción

  1. Hardware: Montar ESP8266 + OLED + SD Card en el bus SPI/I2C.
  2. SD: Formatear SD en FAT32 y crear el archivo config.json.
  3. Config: Conectar por WiFi al WASP-STATION-CFG para verificar que el servidor lee la SD.
  4. Matriz: Soldar la matriz de 16 botones con sus 16 diodos.
  5. Mapeo: Usar la interfaz web para asignar qué botón dispara qué nota MIDI.
